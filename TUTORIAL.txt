STEPS 1
Opsi 1: buka https://github.com/coreybutler/nvm-windows/releases/download/1.2.2/nvm-setup.zip untuk download NVM

Jika gagal
Opsi 2: Buka halaman ini https://www.nvmnode.com/guide/download.html , atau 
Download versi terbaru NVM dari github melalui link yang sudah dibuka

STEPS 2
tekan 'WIN + R' ketik 'CMD' lalu 'ENTER'
cek versi NVM dengan mengetikkan 'nvm -v' 
Jika tidak muncul version maka coba search nvm menggunakan terminal sebagai administrator
dengan cara:
- cari CMD di pencarian windows
- lalu klik kanan dan runs as administrator
- kemudian ketik 'where nvm' apabila file menunjukkan lokasi nvm.exe copy path yang tersalin tersebut

lalu:
- tekan 'WIN + R' lalu ketikkan 'sysdm.cpl'
- lalu pilih 'Environtment Variables...'
- bagian bawah pada pilihan System variables cari PATH kemudian Edit
- Tekan new kemudian masukkan path yang nvm.exe yang sudah di copy

STEP 3
setelah itu coba kembali test di terminal user dengan 
tekan 'WIN + R' ketik 'CMD' lalu 'ENTER' 
lalu cek versi NVM dengan nvm -v

apabila muncul, buka terminal file ini,
kemudian jalankan command ini

nvm install 22
npm install
npm run dev

lalu buka link localhost:3000 yang muncul dalam terminal
